Leadership Tracker

If you haven't created a folder yet:

1. Open Google Drive in a new tab.

2. Create a new, empty folder (e.g., "Ward Leadership" or "Stake Presidency").

3. Right-click the folder, select "Share," and add each member of your bishopric or presidency as an Editor.

4. Come back here and tap the button below to select that folder.

Important: Only share the folder with named accounts of your leadership team. Never set it to "Anyone with the link."

Select every Leadership Tracker file in this folder.

Tap the button, then select all of them — the picker is already inside your folder and shows only the app's files. They are:

config.json, members.json,
callings.json, callings-archive.json,
interviews.json, interviews-archive.json,
programs.json, programs-archive.json
