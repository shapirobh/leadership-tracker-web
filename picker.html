Select Your Folder

Choose the Google Drive folder where Leadership Tracker will store your callings, interviews, and meeting data.

If you haven't created a folder yet:

1. Open Google Drive in a new tab.

2. Create a new, empty folder (e.g., "Ward Leadership" or "Stake Presidency").

3. Right-click the folder, select "Share," and add each member of your bishopric or presidency as an Editor.

4. Come back to this page and tap the button below to select that folder.

Important: Only share the folder with named accounts of your leadership team members. Never set it to "Anyone with the link."
Access diagnostic (temporary): to test shared access, you can open the folder in the picker and select a file that another user created (e.g. config.json). This page will then try to read that file and report whether your account is allowed to. Selecting a folder works normally.
